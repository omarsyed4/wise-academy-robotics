→Hi Sam

8

Operators · pointy blocks

Checking blocks: true or false

<(answer) = [7]>
true  if you typed 7
false  if you typed anything else
<(5) > (3)>
true  5 is more than 3
<(2) > (3)>
false  2 is not more than 3
<not <(answer) = [7]>>
true  if the answer is not 7. not flips true and false.

Ask + Operators

Ask, then check

ask [What is 3 + 4?] and wait
if <(answer) = [7]> then
  say [Correct!] for (2) seconds
end
  1. ask shows the question and waits.
  2. You type 7. Now answer is 7.
  3. = checks: is answer the same as 7? True.
  4. It's true, so the cat says Correct!
Correct!

The = block goes in the pointy hole of the if.

10 Try it · 3 minutes

A one-question quiz

when flag clicked
ask [What is 3 + 4?] and wait
if <(answer) = [7]> then
  say [Correct!] for (2) seconds
end
if <not <(answer) = [7]>> then
  say [Try again] for (2) seconds
end
  1. Build it on the cat.
  2. Click the green flag and type 7.
  3. Click it again and type 5.

It works if 7 says Correct! and 5 says Try again.
