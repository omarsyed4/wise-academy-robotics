4 · Order of work

  1. Students bring the words above to class. Coach types them into docs/print/innovation-board.py (move each into the box's text, delete its “needs” line).
  2. Run python3 docs/print/innovation-board.py, then node docs/print/print.mjs. It rebuilds the website board and this PDF pack, and stops if any text no longer fits its box.
  3. Only then send the three posters to print. Print the photos the same week.
  4. Glue the posters onto the board panel by panel, then glue each photo and sketch into its dashed window (sizes printed inside each window).

Students do the work: only words a student said or wrote, or the agreed solution, go on the board. The website board (This week → The two trifolds) shows the same boxes with who owns each missing piece.
