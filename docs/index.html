Two practice squads, each simulating a full run. Open a mission to see the code behind it. Drop a screenshot into docs/code/ and it shows up here.

06Leafcutter FrenzyAnt touching the nest, 10 per leaf fragment inside itBlueCoded40

The only mission with measured times so far, at 7.10s and 8.99s. Highest value mission on the plan.

CODE
12Forest ElderCane raised touching the tree 20, support tie around the post 10BlueCoded30

Rated 8 out of 10, the hardest on the plan. The Blue game plan logs this as 20 points. It is 30. The support tie is a separate scoring line, not a bonus.

CODE
03Flip the RockResearch flag down 20, rock returned to its start plus 10RedCoded30

Red rates this hard. Measured at 4 to 5 seconds.

CODE
05Reaching RootsPartially extended 10, or completely extended 20RedCoded20

There is no bonus here. The Red game plan has it written as 10 plus a 10 bonus. It scores 10 or 20, never both. Aiming for a bonus that does not exist means building the wrong attachment.

CODE
01Drone SurveyDrone off the mat 20, LiDAR map flipped with the scan marker in the survey area plus 10RedCoded30

Red rates this easy. The bonus is the harder half.

CODE
08TangledVine touching the mat, one actionNo owner30

Best points per line of code on the whole board, and in neither squad's plan. Every student rated it top tier in their notebook back in September.

CODE
10Fragile MicrohabitatsSpider and snail habitats left in their starting positionsFree20

No code. Twenty points for not hitting anything, which means every other route has to stay clear of them.

00Equipment inspectionRobot and all equipment inside one launch area, under 12 inchesDrill20

Worth more than Window to the Past and takes thirty seconds to practise. The pack down should be identical every time.

00Precision tokensSix at the start, worth 50 pointsDrill50

Six tokens and five tokens both pay 50, so the first interruption outside home is free. The second costs 15, more than Mission 11 is worth. Wait the extra two seconds for the robot to come home.
